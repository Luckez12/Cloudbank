# Vidnest v2.1.0 — English and Malay subtitles only

Overlay ZIP contents at Cloudbank repository root beside existing manifest.json. No extra Cloudbank folder, app patch, workflow change or deletion. Refresh to Vidnest v2.1.0. Provider includes the v2.0.1 isolated CryptoJS decoder. Video API routes, decrypt, headers, selected URL and media verification stay unchanged.

Only subtitle tracks positively labelled English (en/eng) or Malay (ms/msa/may/Malay/Bahasa Melayu) are forwarded. Indonesian, Malayalam (mal), other languages and unlabelled tracks are excluded. Source-API captions are merged with VDRK v1/v2 sidecar metadata. Movie route uses exact TMDB ID; TV route includes requested season/episode. Both subtitle metadata reads start in parallel with video discovery and share a 3.5-second overall subtitle budget. If one source stalls, completed tracks from the other are retained. Subtitle errors, empty results and timeouts do not remove working video. Abort pending lookups when possible; no-video result stops subtitle work. No subtitle file downloads during discovery. No translation.

Normalize language fields for VUEO, preserve caption headers, label variants and CC; encode spaces in subtitle URLs while preserving existing escapes/query values. Deduplicate by URL and cap at eight English plus eight Malay tracks. Subs may add up to 3.5 seconds from discovery start when media is ready sooner; no additional 3.5-second wait starts after video completion.
