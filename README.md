# Cloudbank

Koleksi provider JavaScript untuk app yang menyokong repository Nuvio.

## Cara install

1. Dalam Nuvio, buka **Settings → Local Scrapers**. Untuk app lain yang serasi, buka bahagian provider/repository dalam Settings.
2. Pilih pilihan untuk menambah repository dan tampal URL ini:

```text
https://raw.githubusercontent.com/Luckez12/Cloudbank/refs/heads/main/manifest.json
```

3. Simpan dan tunggu senarai provider dimuatkan.
4. Aktifkan provider yang mahu digunakan, kemudian buka movie atau series untuk mencari stream.

Nama menu mungkin berbeza mengikut app. Provider V2/V3 ialah pilihan berasingan; pilih versi yang berfungsi pada peranti kau.
